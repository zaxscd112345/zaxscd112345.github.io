บทที่ 2 (เจาะลึกข้อมูลและเครื่องหมายคำนวณ)

ชนิดข้อมูลพื้นฐานและตัวดำเนินการทางคณิตศาสตร์ (Data Types & Operators)

1. ชนิดข้อมูลพื้นฐานใน Python (Data Types)

คอมพิวเตอร์จำเป็นต้องรู้ว่าข้อมูลที่เราเก็บคืออะไร เพื่อจะได้ประมวลผลถูกวิธี โดยชนิดข้อมูลหลักๆ ที่ต้องรู้มีดังนี้ครับ:

1. Integer (int - จำนวนเต็ม)

เช่น 10, -5, 0, 1000

2. Float (float - จำนวนทศนิยม)

เช่น 3.14, 99.99, 0.5

3. String (str - ข้อความ/ตัวอักษร)

ต้องอยู่ในเครื่องหมายคำพูด เช่น "Hello" หรือ 'Python'

4. Boolean (bool - ค่าความจริง)

มีแค่ 2 ค่าคือ True (จริง) และ False (เท็จ)

datatypes.pyPython 3.12
# ตรวจสอบชนิดข้อมูลด้วยฟังก์ชัน type()
print(type(42))       # ผลลัพธ์: <class 'int'>
print(type("สวัสดี"))  # ผลลัพธ์: <class 'str'>

2. ตัวดำเนินการทางคณิตศาสตร์ (Operators)

เครื่องหมาย หน้าที่ / การใช้งาน ตัวอย่าง
+บวก5 + 3 (ได้ 8)
-ลบ5 - 3 (ได้ 2)
*คูณ5 * 3 (ได้ 15)
/หาร (ได้ทศนิยม)5 / 2 (ได้ 2.5)
//หารปัดเศษทิ้ง (Integer Division)5 // 2 (ได้ 2)
%หารเอาเศษ (Modulo)5 % 2 (ได้ 1)
**ยกกำลัง2 ** 3 (ได้ 8)
