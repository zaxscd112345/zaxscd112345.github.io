บทที่ 5

ฟังก์ชันและการรับส่งค่า (Functions & Scope)

ฟังก์ชันคือบล็อกคำสั่งที่ถูกห่อหุ้มไว้เพื่อทำงานเฉพาะกิจ สามารถเรียกใช้งานซ้ำได้ง่ายด้วยการประกาศ def และส่งค่าผลลัพธ์ผ่าน return

lesson_05_functions.pyPython 3.12
# ประกาศฟังก์ชันคำนวณราคาสุทธิพร้อมส่วนลด
def calculate_discount(price, discount_percent):
    discount_amount = price * (discount_percent / 100)
    final_price = price - discount_amount
    return final_price

# เรียกใช้งานฟังก์ชัน
net_total = calculate_discount(2500, 15)
print(f"Net Price after discount: {net_total} THB")

หลักการออกแบบฟังก์ชันที่ดี

  • ฟังก์ชันหนึ่งควรทำหน้าที่อย่างเดียวให้สมบูรณ์ (Single Responsibility Principle)
  • การใช้ Default Arguments เช่น def connect(host, port=3306): ช่วยให้ฟังก์ชันยืดหยุ่นขึ้น
