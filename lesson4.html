Chapter 4

การวนซ้ำ (Loops: For & While)

คำสั่งวนซ้ำช่วยให้เราสั่งให้คอมพิวเตอร์ทำงานเดิมซ้ำ ๆ ได้โดยไม่ต้องเขียนโค้ดบรรทัดเดิมซ้ำกันหลายรอบ พร้อมคำอธิบายโค้ดทุกบรรทัดอย่างละเอียดเพื่อความเข้าใจง่าย

🔄 1. คำสั่ง For Loop (วนซ้ำตามจำนวนครั้งที่รู้แน่นอน)

ใช้สำหรับวนลูปผ่านลำดับข้อมูลหรือช่วงตัวเลขที่กำหนด โดยสั่งงานซ้ำ ๆ ตามจำนวนรอบที่ระบุ

ตัวอย่างโค้ดพร้อมคำอธิบายทีละบรรทัด (Line-by-Line):
# เริ่มต้นลูป for โดยให้ตัวแปร i วนค่าตั้งแต่ 0 ถึง 2 (ทั้งหมด 3 รอบ)
for i in range(3):
    # พิมพ์ข้อความคำว่า "รอบที่:" ตามด้วยค่าปัจจุบันของตัวแปร i ในรอบนั้น ๆ
    print("รอบที่:", i)
💡 ผลลัพธ์ที่จะแสดงบนหน้าจอ:
รอบที่: 0
รอบที่: 1
รอบที่: 2

⏳ 2. คำสั่ง While Loop (วนซ้ำจนกว่าเงื่อนไขจะ,เป็นเท็จ)

ใช้เมื่อเราไม่รู้จำนวนรอบที่แน่ชัด แต่ต้องการให้ลูปทำงานต่อไปเรื่อย ๆ ตราบใดที่เงื่อนไขยังคงเป็นจริง (True)

ตัวอย่างโค้ดพร้อมคำอธิบายทีละบรรทัด (Line-by-Line):
# กำหนดตัวแปรชื่อ count ให้มีค่าเริ่มต้นเท่ากับ 3
count = 3

# เริ่มลูป while โดยจะทำงานซ้ำเรื่อย ๆ ตราบใดที่ค่า count มากกว่า 0
while count > 0:
    # แสดงข้อความนับถอยหลังพร้อมกับค่าของ count ในรอบนั้น
    print("นับถอยหลัง:", count)
    
    # ลดค่าของตัวแปร count ลงทีละ 1 ในแต่ละรอบ เพื่อไม่ให้ลูปวนไม่รู้จบ (Infinite Loop)
    count = count - 1

# เมื่อเงื่อนไขใน while เป็นเท็จ (count ไม่มากกว่า 0 แล้ว) ลูปจะจบลงและมาทำบรรทัดนี้
print("หมดเวลา! 🚀")
💡 ผลลัพธ์ที่จะแสดงบนหน้าจอ:
นับถอยหลัง: 3
นับถอยหลัง: 2
นับถอยหลัง: 1
หมดเวลา! 🚀
