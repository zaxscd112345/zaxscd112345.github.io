บทที่ 4

การวนซ้ำด้วยลูป For & While (Loops)

ต้องการทำงานซ้ำๆ ใช้ For Loop เมื่อรู้จำนวนรอบ หรือ While Loop เมื่อวิ่งตามเงื่อนไขครับ:

example_04.pyPython 3
# For Loop
for i in range(1, 4):
    print(f"For round: {i}")

# While Loop
count = 2
while count > 0:
    print("Running...")
    count -= 1

อธิบายวิธีเขียนแบบ "ท่อนต่อท่อน"

  • range(1, 4) : สร้างลำดับตัวเลขตั้งแต่ 1 ถึง 3 สำหรับให้ For วนลูป
  • while condition : วนซ้ำไปเรื่อยๆ จนกว่าเงื่อนไขจะเป็น False (ระวัง Infinite Loop!)
