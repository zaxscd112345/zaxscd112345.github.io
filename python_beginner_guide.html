คู่มือ Python ฉบับเริ่มต้น: ตัวแปร และ ฟังก์ชัน

อธิบายละเอียดยิบ เข้าใจง่ายเหมือนคุยกัน สำหรับคนไม่มีพื้นฐานมาก่อน

1. ตัวแปร (Variables) คืออะไร?

ลองนึกภาพว่าคุณกำลังเก็บของเล่นใส่กล่อง แล้วเอาป้ายชื่อแปะไว้ข้างกล่อง เพื่อให้รู้ว่าข้างในคืออะไร... "ตัวแปร" ในคอมพิวเตอร์ก็คือกล่องเก็บข้อมูลเหล่านั้นครับ!

เวลาที่เราเขียนโปรแกรม เราต้องการจำค่าอะไรบางอย่าง เช่น คะแนนสอบ ชื่อผู้เล่น หรือราคาสินค้า เราก็สร้าง "ตัวแปร" ขึ้นมาเพื่อเก็บข้อมูลนั้นไว้ แล้วเรียกใช้งานได้ตลอดเวลาโดยไม่ต้องจำค่าเอง

# ตัวอย่างการสร้างตัวแปรใน Python name = "สมชาย" # สร้างกล่องชื่อ name เก็บข้อความ "สมชาย" score = 95 # สร้างกล่องชื่อ score เก็บตัวเลข 95 is_passed = True # สร้างกล่องชื่อ is_passed เก็บสถานะความจริง (True/False)

วิธีตั้งชื่อตัวแปร (ข้อควรรู้สำหรับมือใหม่)

  • ชื่อต้องสื่อความหมาย: ควรตั้งให้รู้ว่าเก็บอะไร เช่น price, student_name ไม่ควรตั้งมั่วๆ เช่น x1, asdf
  • ห้ามเว้นวรรค: หากมีหลายคำให้ใช้ขีดล่าง (Underscore) เชื่อม เช่น my_score
  • ห้ามขึ้นต้นด้วยตัวเลข: เช่น 1name แบบนี้โปรแกรมจะฟ้อง Error ทันที แต่ใส่ตัวเลขข้างหลังได้ เช่น name1
  • ภาษาไทยใช้ได้แต่ไม่แนะนำ: เพื่อความสากลและความปลอดภัย แนะนำให้ใช้ภาษาอังกฤษเสมอ

2. ฟังก์ชัน (Functions) คืออะไร?

ถ้าตัวแปรคือ "กล่องเก็บของ" ฟังก์ชันก็คือ "เครื่องจักรกลอัตโนมัติ" หรือ "พ่อครัว" ประจำตัวเราครับ!

ฟังก์ชันคือชุดคำสั่งที่ถูกเขียนรวบรวมไว้สำหรับทำงานอย่างใดอย่างหนึ่งให้เสร็จ เมื่อเราเรียกใช้ฟังก์ชันนั้น มันจะทำงานตามที่เราสั่งทันทีโดยที่เราไม่ต้องเขียนโค้ดยาวๆ ซ้ำๆ

เปรียบเทียบให้เห็นภาพ: นึกถึง "เครื่องปั่นน้ำผลไม้" คุณใส่ผลไม้เข้าไป (เรียกว่า Argument หรือข้อมูลนำเข้า) เครื่องปั่นจะทำงานตามกลไก แล้วคั้นน้ำผลไม้ออกมาให้คุณดื่ม (เรียกว่า Return value หรือผลลัพธ์)
# ตัวอย่างการใช้ฟังก์ชันสำเร็จรูปใน Python message = "สวัสดีชาวโลก" print(message) # print() คือฟังก์ชันสำหรับแสดงผลข้อความออกหน้าจอ length = len("Python") # len() คือฟังก์ชันนับจำนวนตัวอักษร (ผลลัพธ์จะได้ 6) print(length)

3. วงเล็บ () ทำหน้าที่อะไร? ในกรณีไหนใช้ได้/ไม่ได้บ้าง?

เครื่องหมายวงเล็บกลม () เป็นสัญลักษณ์ที่มีบทบาทสำคัญมากๆ ใน Python แต่ผู้เริ่มต้นมักจะสับสนว่ามันใช้ทำอะไรและใช้ตอนไหนบ้าง มาดูสรุปแบบละเอียดกันครับ

กรณีที่ 1: "ใช้ได้" และ "ต้องใช้" (กรณีที่บังคับต้องมี)

สถานการณ์ คำอธิบาย ตัวอย่างโค้ด
1. เรียกใช้งานฟังก์ชัน (Function Call) ใช้ตามหลังชื่อฟังก์ชันเสมอ เพื่อบอกว่าเรากำลังสั่งให้ฟังก์ชันนั้นทำงาน และใช้ใส่ข้อมูล (Arguments) เข้าไปข้างใน print("Hello")
len([1, 2, 3])
2. จัดลำดับการคำนวณทางคณิตศาสตร์ ใช้กำหนดลำดับความสำคัญ เหมือนในวิชาคณิตศาสตร์ วงเล็บด้านในจะถูกคำนวณก่อน result = (5 + 3) * 2
(คำนวณ 5+3 ก่อน แล้วค่อยคูณ 2)
3. สร้าง Tuple (ข้อมูลแบบกลุ่มที่แก้ไขไม่ได้) ใช้ครอบข้อมูลหลายๆ ตัวเข้าด้วยกัน coordinates = (10.5, 20.3)

กรณีที่ 2: "ใช้ไม่ได้" (ข้อห้ามและข้อควรระวังสำหรับมือใหม่)

ห้ามใช้วงเล็บ () ในกรณีเหล่านี้เด็ดขาด:
  • ห้ามใช้ครอบเงื่อนไข If-Else แบบภาษาอื่น: ในภาษา C หรือ Java ต้องมีวงเล็บครอบเงื่อนไข เช่น if (x > 5) แต่ใน Python ห้ามใส่ ต้องเขียนว่า if x > 5: เท่านั้น
  • ห้ามใช้สร้างบล็อกคำสั่ง (Code Block): เช่น แทนที่จะใช้ปีกกา {} ในการครอบกลุ่มคำสั่ง Python ใช้การย่อหน้า (Indentation) แทน ห้ามใช้วงเล็บกลมหรือปีกกามาครอบบล็อกคำสั่งเด็ดขาด
  • ห้ามใส่วงเล็บตอนประกาศตัวแปรเดี่ยว: เช่น (score) = 50 ทำได้แต่ไม่มีประโยชน์และผิดหลักไวยากรณ์ในบางบริบท

สรุปเปรียบเทียบการใช้เครื่องหมายวงเล็บ

  • ✅ ใช้ได้ถูกวิธี: print("ยินดีต้อนรับ") (เรียกฟังก์ชัน)
  • ❌ ใช้ผิดวิธี: if (score >= 50): (Python ไม่ต้องใช้วงเล็บครอบเงื่อนไข)
