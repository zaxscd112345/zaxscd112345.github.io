Chapter 6

โครงสร้างข้อมูล (Lists & Dictionaries)

เรียนรู้วิธีเก็บข้อมูลจำนวนมากในตัวแปรเดียวด้วย List (รายการ) และ Dictionary (ข้อมูลแบบจับคู่คีย์-ค่า) พร้อมคำอธิบายทุกบรรทัด

📋 1. การใช้งาน List (รายการข้อมูล)

List ใช้เก็บข้อมูลหลาย ๆ ค่าเรียงต่อกันในตัวแปรเดียว สามารถเพิ่ม ลบ และเข้าถึงข้อมูลด้วย Index (เริ่มต้นที่ 0)

ตัวอย่างโค้ดพร้อมคำอธิบายทีละบรรทัด (Line-by-Line):
# สร้าง List เก็บชื่อผลไม้ 3 ชนิด ไว้ในตัวแปรชื่อ fruits
fruits = ["apple", "banana", "orange"]

# ใช้คำสั่ง append เพื่อเพิ่มข้อมูลคำว่า "mango" ต่อท้ายเข้าไปใน List fruits
fruits.append("mango")

# พิมพ์ข้อมูลใน List ที่ตำแหน่ง Index ที่ 0 (ตัวแรกสุด คือ "apple") ออกทางหน้าจอ
print(fruits[0])
💡 ผลลัพธ์ที่จะแสดงบนหน้าจอ:
apple

📖 2. การใช้งาน Dictionary (ข้อมูลแบบ Key-Value)

Dictionary ใช้เก็บข้อมูลในรูปแบบคู่กัน คือ Key (ป้ายชื่อ) และ Value (ค่าของข้อมูล) คล้ายกับการเปิดพจนานุกรม

ตัวอย่างโค้ดพร้อมคำอธิบายทีละบรรทัด (Line-by-Line):
# สร้าง Dictionary เก็บข้อมูลนักเรียน ในตัวแปรชื่อ student ประกอบด้วย Key และ Value
student = {
    "name": "สมชาย",   # Key คือ "name", Value คือ "สมชาย"
    "age": 20,      # Key คือ "age", Value คือ 20
    "grade": "A"    # Key คือ "grade", Value คือ "A"
}

# เข้าถึงข้อมูลใน Dictionary โดยเรียกผ่าน Key ชื่อ "name" แล้วพิมพ์ผลลัพธ์ออกมา
print(student["name"])
💡 ผลลัพธ์ที่จะแสดงบนหน้าจอ:
สมชาย
